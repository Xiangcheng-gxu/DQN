# 单场景 DQN 推动训练

在当前 UR5e + Robotiq 2F-85 MuJoCo 场景中，学习用 0–7 八个推动动作把红色目标与障碍物分开。

## 启动

现有可用解释器为 `E:\anaconda3\envs\MuJoCo\python.exe`，本次已补装 CPU PyTorch。
也可以用自己的 Python 3.10+ 环境安装依赖：

```powershell
python -m pip install -r requirements.txt
```

正式训练，默认 3 个障碍物、每回合最多 10 个动作：

```powershell
E:\anaconda3\envs\MuJoCo\python.exe train_dqn.py --episodes 10000
```

观察训练时的场景，附加 `--viewer`；输出每个动作的信息，附加 `--verbose`。
默认每回合只输出一行：回合、物体数量、步数、奖励、结束原因、最近 100 回合成功率、epsilon、loss、回放数量、更新次数和耗时。
查看器按仿真进度刷新，不强制实时播放。

短流程检查（预热与批量临时改为 2，仅用于验证代码，不代表训练收敛）：

```powershell
E:\anaconda3\envs\MuJoCo\python.exe train_dqn.py --episodes 2 --max-steps 3 --warmup 2 --batch-size 2 --output results\quick_check --verbose
```

评估和续训：

```powershell
E:\anaconda3\envs\MuJoCo\python.exe evaluate_dqn.py --checkpoint results\dqn\last.pt --episodes 100 --output results\dqn\evaluation.csv
E:\anaconda3\envs\MuJoCo\python.exe train_dqn.py --resume results\dqn\last.pt --episodes 1000
```

`--episodes` 在续训时表示追加回合数。续训从检查点读取网络、目标网络、优化器、经验、学习计数和随机状态；它从新回合开始，不恢复中断动作的仿真现场。仅加载自己信任的检查点。
新训练不会覆盖已有的 `training.csv` 或 `last.pt`，需要更换 `--output` 或使用 `--resume`。

### 观察和特征

从当前模型的 `topdown_depth` 相机采集真实渲染的 RGB-D，根据相机投影转换到 0.5 × 0.5 m 工作区，生成 250 × 250、分辨率 2 mm 的高度图。
高度相对桌面 0.754 m；利用目标的已知红色提取掩码，替代参考工程依赖的外部分割模型。
网络不读取物体真值位置；仿真真值仅用于奖励、越界和验证。

状态维度和排列保留参考结构：

- 目标平移至高度图中心，目标包围盒分为四块，计算 4 个平均高度。
- 上、右、下、左四个 64 × 64 邻域，各做 8 × 8 核、步长 8 的均值池化，各得到 64 个特征。
- 260 个高度特征除以本次最大值；追加目标相对工作区中心的归一化 XY，共 262 维。

边缘裁剪使用补零，空掩码返回有限的零向量，避免参考实现边缘切片和除零问题。
参考的轮廓分割换成红色像素掩码，因此分割边界可能存在像素级差异。

### 网络和学习

`262 → Linear(300) → ReLU → Linear(200) → ReLU → Linear(8)`。
隐藏层之后和输出层采用参考的 `[-0.003, 0.003]` 均匀初始化；首层使用 PyTorch 默认初始化。

保留参考默认参数：Adam `lr=0.001`，MSE 损失，`gamma=0.9`，均匀 FIFO 回放容量 10000，预热 500，batch 32。
每次环境交互存一条真实 `(state, action, reward, next_state, terminal)`，预热后更新一次。
目标网络不计算梯度，并在开始时复制在线网络。

普通 DQN：`target = reward + gamma * (1-terminal) * max Q_target(next_state)`。
配置 `double_dqn: true` 后，用在线网络选择下一动作、目标网络计算其值。

注意参考工程的 `tau=0.999` 表示旧目标网络保留比例：
`target_weights = tau * old_target_weights + (1-tau) * online_weights`。
本实现保留此含义，不与常见的“小 tau 表示更新比例”混用。

动作采用 epsilon-greedy，`epsilon = 0.05 + (0.9-0.05)*exp(-学习更新次数/20000)`。
评估关闭随机探索和学习，只选最大 Q 值动作。

### 动作与物理

- a0–a3：参考原项目对红色掩码做 3×3 高斯滤波、阈值 100、外轮廓提取、轮廓矩质心计算，再采样 +X、+Y、−X、−Y 四个轮廓交点，不再取外接矩形四侧点。主轮廓按参考取轮廓顶点最多者；并列时取面积较大者，忽略零面积噪声。
- 修正参考函数的像素偏差：其检查2×2邻域命中轮廓后返回的却是遍历像素，可能提前一个像素。当前返回实际命中的轮廓像素，并沿对应外侧方向加半个像素，使用像素单元的外缘作为边界，避免2 mm分辨率吃掉5 mm间隙；视觉边界仍有像素级估计误差。
- 基准推点从对应轮廓点向外偏移 **13 mm = 夹爪窄边16 mm的一半 + 5 mm间隙**。尺寸定义在 `Gripper2F85.CLOSED_TIP_ALONG_PUSH_M` / `CLOSED_TIP_ACROSS_PUSH_M`；间隙定义在 `src/action_primitives.py` 的 `PUSH_POINT_CLEARANCE_M`。
- 按参考顺序检查基准点、+X 1 cm、+Y 1 cm、−X 1 cm、−Y 1 cm 共五个候选点。每个点使用随推动方向旋转的 **沿推动16 mm × 横向22 mm** 闭合底部矩形，取其覆盖区域最大高度，选择最大高度最低者；并列取前者。因此 **13 mm 是基准偏移，筛选后起点还可能偏移1 cm**。越出高度图的覆盖区域或非有限高度不参与评分，不把图外区域当作空桌面。
- a4–a7：**不采样边缘推点、不进行五候选筛选**，直接从轮廓质心对应的目标中心向 +X、+Y、−X、−Y 推；不复制参考代码额外的 XY 各加1 cm 偏移。
- 距离默认 8 cm。夹爪局部 Y（侧面）朝推动方向，局部 Z 垂直向下。
- 下降与水平推动默认各 **0.08 m/s**，由原来的0.04 m/s加倍；抬起仍为0.04 m/s，安全高度转向和稳定等待不变。分别在 `configs/dqn.json` 的 `descent_speed_m_s` / `push_speed_m_s` 修改，也可使用 `--descent-speed 0.08 --push-speed 0.08`（训练、续训、评估均支持）。续训保留检查点中已记录的推动速度，需要加参数才覆盖旧值；缺少下降速度字段时采用新的默认值。独立动作演示的下降和推动段由0.30秒缩短为0.15秒，转向/抬起段和闭合/稳定检查保持不变。
- 以**夹爪底部中心**控制；平行闭合修订后重新标定，pinch 到底部的局部轴向偏移为 `0.017626 m`。
- a0–a3 的底部中心高度为**目标顶面以下 5 mm**，a4–a7 为**目标顶面以上 5 mm**，且 a4–a7 均从目标 XY 中心出发。目标顶面高度取自当前 RGB-D 高度图的红色目标区域，中位数估计避免混入邻近障碍物。
- 高度使用桌面相对坐标，`0` 表示底部中心与桌面齐平。例如目标高 30 mm，a0–a3 使用 25 mm，a4–a7 使用 35 mm。动作测试和训练使用同一规划器。
- 候选点局部高度只用于选择 XY，不替换上述目标顶面±5 mm的 Z 高度。该筛选不是整条轨迹的碰撞安全证明，也未覆盖夹爪上部连杆。`test_scene --test-actions` 与训练均通过 RGB-D 和 `plan_observation` 获取动作起点。
- 模型采用平行推动模式：保持原四连杆和单 tendon 执行器，增加 follower 与 spring-link 的反向联动，抑制指垫自适应内倾；coupler 上限调整至 `0.03 rad` 以容纳闭合时约 `+0.021 rad` 的转角。手指仍由动力学求解，不直接设置关节位置。这会限制原模型的自适应包络抓取自由度。
- 完全闭合、两侧指垫相对基座对齐且互相平行后，检查连续 0.1 秒内所有连杆的位置波动和平均漂移，再允许动作。接触使夹爪偏开或指垫倾斜时暂停轨迹、重新闭合；闭合或 IK 失败则终止回合并明确记录。
- 转向在上方完成，下降、水平推动、抬起逐物理帧解固定姿态 IK。每次推动后停在抬起位置，不再返回原点；在这里取图，随后直接前往下一动作的上方起点。IK优先使用当前关节姿态，必要时仅在离线规划数据中使用中立姿态作为求解种子，不移动真实机械臂回原点。
- 训练高度图相机与 `D435iCamera` 的RGB/深度采集均使用 `RobotHiddenRenderer`：通过相机专属 `MjvOption.geomgroup` 排除组2（机械臂/夹爪外观）和组3（机械臂/夹爪碰撞几何）；D435i外壳移到组1，桌面、目标和障碍物仍在组0。直接使用原模型和实时数据，不复制模型、不改透明度、不事后抹除像素，RGB与深度均能看到机械臂后方物体。查看器继续显示机械臂，碰撞、关节和控制不变。启动时检查分组互斥，避免将场景物体误隐藏。原标定流程仍保留其自己的渲染方式。

机械臂沿用当前测试的运动学位置跟踪；夹爪、目标和障碍物在 `mj_step` 中正常进行动力学和接触计算。推动过程中不直接修改物体位置，也不重新施加聚拢力。
物体仍沿用已有的 XY 滑动关节约束，因此这是平面推动任务，不支持翻倒、堆叠或真实抓取。MuJoCo 接触求解有数值误差，并非数学意义上的零穿透。

### 奖励与结束

沿用参考单 DQN 推动任务的四档奖励：

| 条件（按此优先级） | 奖励 | 结束 |
| --- | ---: | --- |
| 动作执行失败、任意物体底面越界、目标丢失 | −10 | 是 |
| 目标与所有障碍物的最小底面边缘间距大于 2 cm | +10 | 是 |
| 前后高度差至少 8 mm 的像素不超过 500 个 | −5 | 否 |
| 其余有效推动 | −1 | 否 |

达到最大步数算截断，保留非终止 TD 自举；成功/失败终止不自举。
成功表示目标已分离、为后续抓取腾出空间，不代表已完成抓取。
每回合初始状态必须未达到分离条件；随机生成失败最多重试 12 次并报错。

输出在 `results/dqn/`：`config.json`、逐回合 `training.csv`、定期 `episode_XXXXXX.pt`、最新 `last.pt`。

初版验证记录：5 项学习回归测试通过；260 个高度特征与参考函数逐维比较，最大误差小于 `3e-7`；另已运行短训练、检查点续训和独立评估。

动作高度修订后，新增了 4 种目标高度 × 8 个动作的高度与中心起点回归检查。高于目标顶面的动作可能只推动更高的邻近障碍物，也可能空推；不强制伪造物体移动。
旧固定高度版本及 a4 低于目标顶面的 `target_relative_v1` 检查点包含不同动作语义的经验，不能用于当前 `target_relative_v2` 动作定义下续训/评估。

推点修订验证：19项回归通过，含五个候选分别胜出、矩形覆盖随方向旋转、轮廓像素外缘、13 mm外偏、a4–a7不调用采样，以及闭合尺寸的物理测量。另在同一seed=7初始clutter分别实际执行八个动作，均无闭合/IK失败；四个方向基准点的实际指端间隙约3.9–6.0 mm，差异来自视觉边界估计。a4/a5在该布局为空推，未伪造位移。短训练2回合产生4条经验、3次网络更新，不代表已收敛。
